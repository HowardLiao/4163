Network Architecture

網路架構：IT／OT 分區與兩廠互連

依 IEC 62443 與 Purdue 模型分區。機台與量測設備留在 OT 區，資料經工業 DMZ 的邊緣閘道往上送；兩廠以 SD-WAN 雙線互連，雲端只走私有連線。

分區原則

OT 設備不直接連外網。機台資料只能經工業 DMZ 的邊緣閘道往上送，雲端與 IT 區不得反向直連機台。

兩廠互連

南屯與后里以 SD-WAN 主線加備援線互連；量測各廠頻寬後設定機台資料與 ERP 流量的優先權。

斷線不停線

邊緣閘道在斷線時把工序與檢驗資料寫入本地佇列，產線照常作業；復網後依時序自動補傳，不重複入帳。

Data Lakehouse

資料湖倉：三層結構與傳輸節奏

兩廠都在台中，頻寬相對寬裕，所以機台與工序資料可以近即時（分鐘級）上傳；SAP 財務與庫存做每日結算；日本與美國據點每日離峰彙總一次。

Bronze 原始層

Security & Compliance

資安與醫材法遵

雙軌防護

邊界 WAAP＋旁路 API 安全

邊界 WAAP 在入口即時攔截已知攻擊；旁路 API 安全以流量鏡像分析行為，找出未列管 API 與越權讀取（例如換工單號偷看其他客戶圖面），再把封鎖規則回送 WAAP。

OT 資安

IEC 62443 分區與管道

機台 PC 不上網、USB 管控、遠端維護只經跳板主機並錄影；修補先在測試機驗證，避免影響產線。

資料完整性

電子紀錄可稽核

依 FDA 21 CFR Part 11 與 ISO 13485：電子紀錄要有稽核軌跡、電子簽章與保存期限，資料符合 ALCOA+（可歸屬、清楚、即時、原始、正確）。

資料保護

設計圖與客戶資料不外流

依資料分級決定可上雲與可進 AI 的範圍；客戶圖面與報價採列級權限與遮罩；日本個資依 APPI、美國廠依當地規定。
